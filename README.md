#Aetee's Bakehouse

Welcome to the Aetee's Bakehouse codebase! This is the storefront and admin dashboard for Aetee's Bakehouse, enabling customers to explore the menu, place orders, and track them.

## 🚀 Tech Stack

- **Framework:** [Next.js](https://nextjs.org/) (v16+)
- **UI Library:** [React](https://react.dev/) (v19+)
- **Database ORM:** [Prisma](https://www.prisma.io/)
- **Payments:** [Razorpay](https://razorpay.com/)
- **Maps/Location:** [Leaflet](https://leafletjs.com/) & React Leaflet
- **Image Processing:** [Sharp](https://sharp.pixelplumbing.com/)
  - **Analytics:** Vercel Analytics

## 🛠️ Getting Started

First, install the dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## 📦 Scripts

- `npm run dev`: Starts the Next.js development server.
- `npm run build`: Generates the Prisma client and builds the application for production.
- `npm run start`: Starts the production server.
- `npm run lint`: Runs ESLint to analyze the code for issues.

## 🎨 Design System

The application follows a specific design language to create a rich and premium aesthetic:
- **Colors:** Deep Chocolate Brown (`#5a3424`), Soft Buttercream Yellow (`#f8ecc2`), Light Warm Grey (`#f4f1eb`), Clean White (`#FFFFFF`).
- **Typography:** Oswald for bold headings, Inter for clean body and UI text.
- **Component Styling:** Pill-shaped buttons (`border-radius: 9999px`), soft rounded corners (`8-12px`) for cards with subtle, warm drop shadows.

For more details on the visual identity and components, please check the `design.md` file in the root directory.
